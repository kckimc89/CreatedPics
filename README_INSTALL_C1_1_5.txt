우리 가족 창작사진관 MASTER C1.1.5

기존 C1.1.4의 AI 자동 누끼 처리 코드와 IndexedDB 저장소 이름을 그대로 유지합니다.

새로운 기능:
1. 다시 편집 후 기본 저장은 새 작품으로 추가 (기존 작품은 보존)
2. 기존 작품 수정 저장은 별도 버튼과 확인창으로만 실행
3. 가족이 촬영한 여행사진을 배경으로 불러오기
4. 명소대백과에서 별도로 내보낸 명소 사진을 배경으로 사용 (직접 자동 연동 아님)
5. 여행지 이름 기록, 배경 위치/확대 조절, 저장 후 다시 편집

설치: 창작사진관 전용 GitHub 저장소에 index.html / app.js / style.css / manifest.webmanifest 네 파일만 교체하세요.
기존 familypics, 명소대백과, Supabase 설정 파일은 변경하지 않습니다.
Safari 웹사이트 데이터는 절대 삭제하지 마세요.

시험: 기존 우주 작품 열기 → 다른 작품 만들기 → 꽃밭으로 변경 → 새 작품으로 저장 → 전시관에 두 작품 확인.
추가 시험: 사진 앱 또는 파일 앱의 가족 여행사진을 배경으로 선택 → 자동 누끼 인물 배치 → 새 작품으로 저장 → 재편집 확인.

주의: 이 버전은 명소대백과의 DB를 읽는 직접 연동이 아닙니다. 명소대백과에서 사진을 파일로 내보낼 수 있을 때 수동 선택하여 활용하는 방식입니다.
이미지/편집정보는 Safari 로컬 IndexedDB에 저장됩니다. 새 작품이 많아지면 저장용량이 부족할 수 있으니 전체 백업과 이미지 내보내기를 병행하세요.
실제 iPad Safari 동작은 사용자 기기에서 추가 검증이 필요합니다.
