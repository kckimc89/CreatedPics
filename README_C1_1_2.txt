우리 가족 창작사진관 MASTER C1.1.2 — 로컬 단색 배경 제거 시험판

C1.1.1을 기반으로 한 패치입니다. 기존 C1.1.1에서 AI 모델 모듈 CORS 접근 실패가 발생해 외부 CDN을 사용하는 자동 AI 인물 분리 버튼을 제거하고, 인터넷 없이 실행되는 배경색 기반 모서리 자동 제거를 보강했습니다.

중요: 이것은 AI 인물 분리 기능이 아닙니다. 색이 비교적 일정한 배경(스튜디오 회색, 흰 벽 등)에서만 좋은 결과를 기대할 수 있습니다. 옷과 피부가 배경색과 비슷하면 일부가 지워질 수 있으므로 복구 붓/되돌리기 기능을 사용하세요.

설치: 창작사진관 저장소의 index.html, app.js, style.css, manifest.webmanifest 교체. familypics, config.js 및 기존 가족사진 데이터는 손대지 않습니다. 저장 DB 이름을 변경하지 않았습니다.

시험: 아이패드에서 사진 선택 → 누끼 → 민감도 52 → 단색 배경 자동 지우기. 과하게 지워지면 되돌리기 후 민감도를 낮춰 재시도하세요. 사진 원본은 변경하지 않습니다.

정식 AI 자동 누끼 기능을 자체 호스팅하려면 MediaPipe의 실행 JS/WASM 파일과 AI 모델 파일을 별도 확보해 검증해야 합니다. 현재 패키지에는 들어 있지 않습니다.

주의: Safari의 브라우저 저장 데이터는 영구 보관을 보장하지 않습니다. 작품 PNG와 전체 백업을 별도 보관하세요.
