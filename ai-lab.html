✨ 시작 안내 · GPT 창작방 연결

먼저 아래에서 사진·장면·모습을 고른 다음 창작 요청을 복사해 GPT에서 완성해요.

사진과 장면을 선택한 후 복사하세요. 작업마다 새로운 일반 GPT 창작방을 열고, 끝나면 필요한 작품을 백업한 후 GPT 대화방과 라이브러리 파일을 직접 삭제하세요.

② 가족여행 창작 방식 고르기

기존 가족과 여행 배경은 유지하고 아이 한 명만 자연스럽게 추가합니다.

기존 가족여행 사진을 위에서 고른 후, 추가할 아이 사진 한 장을 선택해 주세요. 두 원본은 변경하지 않습니다.

추가할 아이 사진을 고르세요

아이 사진은 이 작업 중에만 참고합니다. GPT에는 두 사진을 직접 첨부해야 합니다.

첫 작품부터 원본 가족의 얼굴·아이의 신체 비율·손잡는 두 손의 연결이 자연스럽게 나오도록 요청합니다.

완성 작품은 기존 ⑤에서 가져와 평가하고 보관합니다. 저장되는 기준 원본은 여행사진이며 추가 아이 사진은 작품 기록에 따로 저장하지 않습니다.

② 타임머신 창작 방식 선택

①에서 실제 아이 또는 가족사진 한 장을 고른 뒤, 시간여행할 시대를 선택하세요. 원본 얼굴을 최대한 보존합니다.

🔒 기준 사진 = ① 과거 가족사진

과거 아이·기존 가족·배경·옷·자세·구도를 그대로 둡니다. 이 사진이 완성사진의 바탕입니다.

➕ 추가할 사람 = ② 현재 아이 한 명

현재 아이의 사진 배경은 사용하지 않습니다. 현재 아이만 과거 사진의 빈 공간에 자연스럽게 넣습니다.

GPT 사진 첨부 순서도 동일하게: 과거 사진 먼저 → 현재 아이 사진 나중. 이미지를 올릴 때 다른 작품이나 이전 생성 이미지를 섞지 마세요.

추가할 현재 아이 사진을 골라 주세요

현재 아이 참고사진은 이 작업 중에만 사용하며, 작품 저장소나 백업에 별도로 저장하지 않습니다.

가장 안전한 첫 시험: 「현재 아이만 추가」를 선택합니다. 과거 사진 속 사람·배경의 변화 없이 현재 아이가 들어가는 것을 먼저 확인한 뒤 손잡기 등을 시험합니다.

모든 시간여행은 상상 속 창작사진입니다. 실제 가족의 원본 얼굴을 최대한 보존하고 미화하지 않으며, AI가 만든 새 얼굴을 원본으로 삼지 않습니다.

🔒 가족사진 원본 보호 · 공통 합성

기존 가족사진을 바탕으로 현재 아이 한 명을 추가합니다. 가족여행과 타임머신이 같은 기능을 사용합니다.

기존 방식입니다. 현재 사진 두 장을 GPT에 직접 첨부하고 요청문을 사용합니다. GPT가 사진 전체를 다시 생성할 수 있으므로 기존 인물의 동일성을 보장하지는 못합니다.

과거 사진이든 현재 가족사진이든, ①에서 선택한 첫 번째 사진을 그대로 사용합니다. 두 번째 사진의 아이만 합성합니다. 두 번째 사진은 가족여행/타임머신 메뉴에서 고릅니다.

아래 현재 아이 사진에서 아이의 윤곽을 따라 점을 여러 개 찍으세요. 마지막에 「윤곽 완성」을 누르면 바깥쪽 배경이 제거됩니다. 자동 배경 제거가 아니라 수동 윤곽 선택입니다. 손·머리카락의 세밀한 가장자리는 거칠 수 있습니다.

현재 아이 사진을 고르면 윤곽 작업이 가능합니다.

투명하지 않은 사진은 받지 않습니다. 일반 사진은 왼쪽의 「윤곽 직접 따기」를 사용하세요.

기본 사진과 추가할 아이를 선택해 주세요.

캔버스에서 아이를 끌어서 위치를 바꾸고 슬라이더로 크기를 조절하세요. 기존 가족사진의 다른 부분은 편집하지 않습니다.

원본 가족사진과 기존 보관 작품은 변경하지 않습니다. 합성 결과를 ⑤로 보내면 별도 작품으로 보관할 수 있습니다. 이 화면은 네트워크로 사진을 자동 전송하지 않습니다.

⚙️ 부모용 · 요청문 확인 및 추가

앱이 만든 기본 요청문

아이의 장면·표정·자세·의상 조건입니다. 이 내용은 실수로 지워지지 않도록 보호됩니다.

필요한 내용만 추가하세요. 기본 요청문과 아이가 말한 내용 뒤에 자동으로 합쳐집니다.

GPT에 보낼 최종 요청문

⑤ 완성사진 가져오기

ChatGPT에서 이미지만 → 다운로드한 뒤 돌아와서 방금 받은 사진을 골라 주세요. 사진 앱에 먼저 옮기지 않아도 됩니다. 파일을 선택할 때 다운로드 폴더나 사진 보관함을 고를 수 있습니다.

👩 부모용 · 제목과 작품 상세 관리

장면과 제목은 저장할 때 기록됩니다. 기존 보관 작품을 선택한 후에는 ‘정보 수정’으로 이름을 바로잡을 수 있습니다. 새 작품은 항상 별도로 저장합니다.

⑥ 나의 창작 작품

사진을 누르면 그 작품의 메뉴가 나타납니다. 작품을 다시 고치고 싶으면 「💬 GPT에서 고치기」를 눌러 GPT 창작방에서 말로 수정하세요.

작품을 한 번 누르면 그 작품 바로 아래에 사진 앱 저장 · 1장 백업 · 삭제 메뉴가 나타납니다.

👩 부모용 · 창작대화방 연결

ChatGPT에서 미리 만든 창작 전용 대화를 열고, 주소창의 대화 주소(chatgpt.com/c/...)를 복사해 아래에 저장하세요. 공유 링크는 사용하지 않습니다.

대화방을 연결하지 않으면 ChatGPT 새 대화를 엽니다.

브라우저에서 대화방 주소만 저장합니다. 원본 사진이나 계정 비밀번호는 저장하지 않습니다. GPT 창작방은 Safari에서 처음 한 번만 열어 두고, 이후에는 앱 탭과 GPT 탭 사이를 직접 전환해 사용하세요. 자동 첨부·붙여넣기·전송은 할 수 없습니다.

💾 저장 상태
