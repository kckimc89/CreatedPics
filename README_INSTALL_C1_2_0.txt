우리 가족 창작사진관 MASTER C1.2.0 — 환상 사진관

기준: 기존 MASTER C1.1.6 (사용자가 작품 2장, 즐겨찾기, 슬라이드 검증)

[이번 버전]
- 환상 배경 6종: 빛나는 꽃정원 / 무지개 구름나라 / 달빛 동화성 / 산호 궁전 / 오로라 계곡 / 별빛 마법숲
- 각 배경은 직접 제작한 창작 일러스트로, fantasy_assets.js에 포함되어 있습니다. 별도 이미지 서버 불필요.
- 배경 그림 미리보기 버튼, 배경에 어울리는 장식 자동 배치, 장식 지우기
- 기존 꽃밭·우주·바닷속·성·노을·별빛·단색 배경 유지
- 기존 AI 인물 누끼 코드/기존 작품 저장 DB 이름 변경 없음
- 기본 저장은 새 작품 추가; 기존 전시관 자료 유지
- 가족 여행사진 배경과 명소대백과에서 내보낸 사진도 그대로 가져오기 가능

index.html
app.js
style.css
manifest.webmanifest
fantasy_assets.js  ← 이번에 새로 추가한 필수 파일입니다.

반드시 위 파일들을 기존 '창작사진관' 저장소의 맨 위(루트)에 넣어 주세요.
'familypics' 저장소, 명소대백과 저장소, config.js, .github, assets/vision 폴더는 변경하거나 삭제하지 마세요.
AI 자동 누끼는 기존처럼 assets/vision 폴더의 파일에 의존합니다. 이 ZIP에는 기존 AI 엔진 파일이 들어 있지 않습니다.

[설치 전]
1. 현재 C1.1.6의 '백업·복원'에서 전체 작품 백업을 내려받아 파일 앱이나 iCloud Drive에 따로 보관합니다.
2. 브라우저 저장 데이터 삭제 금지, 기존 웹앱 초기화 금지.
3. 기존 C1.1.6 원본 ZIP을 별도로 보관합니다.

[시험]
1. 새로고침 후 MASTER C1.2.0 확인.
2. '내 작품 전시관'에 기존 우주와 꽃밭 등 작품이 그대로 있는지 확인.
3. '환상 사진 만들기' -> 사진 1장 선택 -> 자동 인물 따기 -> 환상 배경 6종 중 선택.
4. '이 배경에 어울리게 꾸미기' -> '새 작품으로 저장' -> 전시관에서 새 작품 확인.
5. 작품 내보내기, 즐겨찾기, 자동 감상도 확인.

[기술과 범위]
- 환상 배경은 고화질 사진이 아닌 오리지널 일러스트형 시험 소재입니다.
- 인물 포즈/옷을 생성형 AI로 바꾸지는 않습니다.
- 사진 원본은 변경하지 않습니다.
- 작품 저장은 Safari IndexedDB 기반으로, 영구 보관을 보장하지 않습니다. 외부로 백업하세요.
- JS 문법 및 ZIP 파일 검사는 완료하였으나, 실제 아이패드 Safari에서 전 과정은 아직 검증하지 못했습니다.
