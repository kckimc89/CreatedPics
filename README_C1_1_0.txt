우리 가족 창작사진관 MASTER C1.1.0 (자동 누끼 시험판)

업로드: index.html, app.js, style.css, manifest.webmanifest 네 파일을 기존 창작사진관 GitHub 저장소에 교체 업로드합니다. familypics 원본 저장소는 수정하지 마세요.

시험: 새로 촬영하여 아이패드 사진 앱에서 정상 열리는 JPG/PNG 사진 → 마법 합성사진 → 사진 가져오기 → ✂️ 누끼 → 자동으로 인물 따기.

최초 실행 시 MediaPipe JavaScript 실행 파일과 사전 학습 모델을 외부 CDN에서 다운로드합니다. 사진 자체는 외부 서버로 전송하지 않으며 분리는 기기에서 실행합니다. 브라우저에 모델 캐시가 저장될 수 있습니다. 외부 AI 생성 서비스는 사용하지 않습니다.

주의: 아이패드 용량이 부족한 상태에서는 모델 다운로드/실행/작품 저장에 실패할 수 있습니다. 충분한 여유 공간을 확보한 후 시험하십시오. 브라우저 저장 데이터를 통째로 지우면 다른 백과사전의 자료가 사라질 수 있습니다.

인물 분리는 사진과 환경에 따라 부정확할 수 있습니다. 실패해도 수동 누끼와 기존 작품은 보존됩니다.

기존 작품의 IndexedDB 이름은 그대로 유지합니다. 중요한 작품은 PNG 내보내기 및 전체 백업을 별도로 해두세요.
