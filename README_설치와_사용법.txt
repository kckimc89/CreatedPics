우리 가족 창작사진관 C1.0.2 — 아이패드 사진 가져오기 안정화

수정 내용: 사진 선택 후 이미지 읽기 및 캔버스 변환 안정화, 대용량 사진 1000px 축소, 파일 읽기 대체 경로, 실패 원인 표시, 회전 슬라이더 오류 수정.

GitHub 창작사진관 전용 저장소의 index.html / app.js / style.css / manifest.webmanifest 파일만 새 버전으로 업로드합니다. 기존 familypics 저장소는 변경하지 마세요.
아이패드 Safari에서 재접속하거나 새로고침 후 상단 MASTER C1.0.2 확인.
마법 합성사진 → 사진 가져오기 → 사진 보관함에서 JPG/PNG 한 장 선택.
'✅ 사진을 가져왔습니다' 또는 '⚠️ 사진 표시 실패' 상태를 확인합니다. HEIC 처리 문제는 JPG/PNG로 다시 시험합니다.
기존 Safari 웹사이트 데이터는 삭제하지 마세요. 저장 작품은 PNG 내보내기와 별도 백업을 권장합니다.
