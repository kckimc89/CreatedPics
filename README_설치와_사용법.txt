C1.0.1 사진 가져오기 수정판
- iPad Safari에서 숨겨진 파일 선택 버튼 대신 보이는 기본 파일 선택 입력을 사용하도록 수정했습니다.
- 기존 앱의 작품 저장소 이름은 변경하지 않았습니다.
- GitHub에 index.html, app.js, style.css, manifest.webmanifest를 최상위 경로로 업로드하세요.
- GitHub에 config.js나 기존 familypics 파일을 올리지 마세요.
- HEIC 형식이 기기에 따라 읽히지 않으면 JPEG 또는 PNG로 시도하세요.
- 기존 Safari 웹사이트 데이터를 삭제하지 마세요.

우리 가족 창작사진관 MASTER C1.0 - 독립형 첫 시험판

1. 소개
- 별도 클라우드 계정 또는 R2/Supabase 없이 작동하는 독립형 사진 창작 도구입니다.
- 아이패드에서 사진을 선택해 배경 합성·사진틀 돌출 작품을 만들 수 있습니다.
- 원본 사진 앱의 사진은 수정되지 않습니다.
- 모든 편집은 브라우저의 캔버스에서 진행됩니다. 서버로 사진을 전송하지 않습니다.

2. 실행
- ZIP 압축을 해제한 후 index.html을 실행합니다. 브라우저 로컬 파일 모드에서는 일부 저장 기능이 제한될 수 있습니다.
- 가장 안정적인 방법은 기존 familypics 저장소와 구분되는 별도의 GitHub Pages 저장소(예: family-creative-studio)에 index.html, app.js, style.css, manifest.webmanifest 4개 파일을 올려 HTTPS로 접속하는 것입니다.
- 기존 familypics 저장소, config.js, 가족 계정, 명소대백과 파일은 변경하지 마세요.
- 주의: github.io 하위 주소를 공유하면 Safari 저장 공간 출처를 공유할 수 있습니다. 중요한 자료는 별도 원본/백업을 꼭 보관하세요.

3. 마법 합성사진
- 마법 합성사진 메뉴 → 사진 가져오기 → 배경 선택 → 인물 이동·크기·기울기 → 장식 → 저장.
- 사진 속 배경 제거는 누끼 탭의 지우개를 사용합니다. 복구 붓·되돌리기를 지원합니다.
- 아이패드 사진 앱에서 피사체를 미리 분리한 투명 PNG를 가져오면 가장 좋은 결과를 얻을 수 있습니다.
- 모서리 배경 지우기는 단순 배경에 대한 실험 기능이며 복잡한 배경에는 정확하지 않습니다.

4. 입체사진
- 입체사진 메뉴 → 누끼 준비 → 액자 선택 → 인물이 액자 앞에 보이도록 배치·그림자 조절.
- 이 버전은 레이어와 그림자를 통한 2.5D 정지 이미지 합성입니다. 진짜 3D 깊이 분석이나 기울임 애니메이션은 아직 포함하지 않았습니다.

5. 작품 저장과 보호
- 전시관에 작품 및 편집 데이터가 IndexedDB로 저장됩니다. 같은 기기의 같은 브라우저/주소에서만 보입니다.
- Safari 웹사이트 데이터 정리, 용량 제한, 앱 삭제 시 저장물이 사라질 수 있습니다.
- 모든 중요한 작품은 PNG로 내보내고, '백업·복원'에서 JSON 전체 백업을 만들어 파일 앱/iCloud Drive 등 별도 위치에 보관해 주세요.
- 아이패드에서 PNG 내보내기는 다운로드/파일 앱으로 저장될 수 있으며, 파일 앱 공유 메뉴에서 '이미지 저장'을 사용할 수 있습니다.

6. 제한과 검증
- 자동 AI 누끼, 사실적 합성, 실제 공간 3D, mp4 내보내기, 가족 간 동기화는 이 시험판 범위가 아닙니다.
- iPad Safari 실기기 테스트는 사용자 기기에서 진행해야 합니다. 브라우저와 사진 형식에 따라 일부 동작이 다를 수 있습니다.
- 투명 PNG나 HEIC 관련 동작은 브라우저가 지원하는 디코더와 공유 방식에 따라 달라집니다.
- 본 버전은 V1.8.2 가족사진관을 대체하지 않는 별도 시험판입니다.
