사진의 배경 지우기

투명한 PNG는 바로 사용됩니다. 일반 사진이라면 아래 도구로 배경을 지울 수 있습니다. 아이패드에서 미리 누끼를 만들어 가져오는 방법이 가장 깔끔합니다.

작품 전체 백업

전시관의 작품 사진과 편집 정보를 하나의 JSON 파일로 내보냅니다. 파일이 커질 수 있으며 Safari의 브라우저 저장 기능보다 별도 백업이 안전합니다.

백업에서 복원

기존 작품은 그대로 두고, 백업에만 있는 작품을 추가합니다. 같은 작품 ID가 있으면 기존 작품을 보존합니다.

기기 저장 안내

이 버전은 계정 없이 단일 기기에서 동작합니다. 같은 GitHub Pages 주소의 다른 앱과 저장 용량을 공유할 수도 있습니다. 기존 명소대백과·음식도감의 Safari 데이터를 삭제하지 마세요.
